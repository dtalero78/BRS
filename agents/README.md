# BRS Claude Code Agents

Specialized sub-agents for the Batería de Riesgo Psicosocial (BRS) system, following the Colombian Ministry of Social Protection standards.

## 🎯 Agent Strategy

Following the YouTuber's methodology: **"Agents that do ONE thing extraordinarily well"**

### Core Principle
- **Problem → Solution → Technology** (never backwards)
- Each agent is an expert in its specific BRS domain
- Meta agent creates all other agents for consistency

## 📂 Agent Hierarchy

### 1. Meta Agent (The Builder)
- **`meta-brs-agent`** - Generates all other BRS agents automatically
  - Creates consistent agent structures
  - Ensures adherence to BRS methodology
  - Scales agent creation for 45+ dimensions

### 2. Core Validation & Calculation Agents
- **`response-validator`** - Validates questionnaire responses
  - Checks completeness (123/97/31 questions)
  - Validates Likert scale range (0-4)
  - Identifies missing or invalid responses

### 3. Planned Agents (To be generated by meta-agent)

#### Calculation Agents
- **`results-calculator`** - Calculate scores using official formula
- **`baremos-classifier`** - Classify risk levels using Tables 29-34
- **`dimension-analyzer-[name]`** - One for each of 45 dimensions
- **`domain-calculator-[name]`** - One for each of 10 domains

#### Report Generation
- **`report-generator`** - Generate PDF reports
- **`interpretation-writer`** - Write risk interpretations
- **`recommendations-generator`** - Generate intervention recommendations

#### Data Management
- **`data-integrity-checker`** - Verify database consistency
- **`migration-runner`** - Execute database migrations safely
- **`backup-creator`** - Create automated backups

#### Testing & Quality
- **`test-runner`** - Run specific BRS tests
- **`api-tester`** - Test API endpoints with BRS data
- **`coverage-analyzer`** - Analyze test coverage

## 🎓 Best Practices

1. **Single Responsibility** - Each agent does ONE thing
2. **Clear Triggers** - Explicit activation phrases
3. **Minimal Tools** - Only essential tools per agent
4. **Official Standards** - Always follow Ministry guidelines
5. **Structured Reports** - Consistent output format
